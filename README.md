# Course Registration Optimization

## Overview
An algorithm-focused project to optimize elective course allocation under limited course capacities, ranked student preferences, CGPA-based policies, and institutional constraints.

## Objectives
- Reproduce the existing college allocation method.
- Implement a preference-optimization algorithm.
- Validate allocation correctness and policy compliance.
- Compare algorithms using preference satisfaction, allocation completeness, capacity utilization, fairness, and runtime.
- Develop a prototype that can eventually integrate with a college registration portal.

## Repository Structure
- `algorithm/` — allocation algorithms, validation, metrics, and tests.
- `backend/` — backend application.
- `frontend/` — student and administrator interfaces.
- `data/samples/` — synthetic sample datasets.
- `docs/` — problem specification, allocation rules, and algorithm design.
- `experiments/` — benchmark configurations and results.

## Technology
- JavaScript / Node.js
- Vitest for automated tests
- React and Express for the application modules

## Current Status
Initial repository setup. Existing allocation rules and optimization objectives are to be confirmed with the institute.

Do not commit identifiable student records, confidential registration data, credentials, or other sensitive institutional information. Use synthetic data for public demonstrations.
